# Qt-Calculator
"A simple calculator built with C++ and Qt."

## Preview
<img width="400" height="212" alt="calculate" src="https://github.com/user-attachments/assets/2534517b-d531-4c4e-8453-9931bc52fa7e" />

## Features

* Number input
* Basic arithmetic operations
* Decimal point input
* Parentheses
* Expression evaluation
* Backspace
* Clear

## Development Environment

* C++
* Qt 6
* Qt Creator

## Structure

* **MainWindow**: Handles the GUI and user input
* **QButtonGroup**: Manages number and operator buttons
* **Eval**: Evaluates mathematical expressions
